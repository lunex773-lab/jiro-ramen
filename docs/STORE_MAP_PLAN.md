# 日本地図の出店マップ 実装計画

オーナーから受け取った「日本地図型・店舗出店マップ実装」（全国 → 地方 → 都道府県 → 市区町村 → 出店候補地、GeoJSON の境界を SVG で描く、拡大縮小・ドラッグ・ピンチ、選んだ区域の強調、候補地の目印、戻る・パンくず、スマホと PC）を、今の出店の仕組みに組み込む計画。

## 1. 今の仕組み（監査）

| 場所 | 今の形 |
| --- | --- |
| 物件 `packages/core/src/data/properties.ts` | 1店目は `home`（来客 ×1・家賃 ×1）。出店の候補は `station`（駅前: 来客 ×1.3・家賃 ×1.6・初期費用70万円）・`residential`（住宅街: ×0.75・×0.7・45万円）・`roadside`（郊外の幹線道路沿い: 12席・×1.0・×0.9・100万円）の3種類だけ。場所（都道府県・市区町村）はない |
| 出店 `sim/stores.ts` の `openStore(s, ctx, propertyId, managerId)` | 12席・評判★4.0以上・社員の店長・初期費用＋運転資金。店の名前は「屋号＋地域＋店」 |
| 画面 `ui/manage.ts`「会社」→「出店（2店舗目以降）」 | 3種類の物件のボタンから選ぶ |
| 共通市場 `market.ts` | 市場の中に駅前・住宅街・郊外の3地域。同じ地域の店どうしが客を取り合い、物件の数に限りがある（`freeSlots`） |
| 共同経営 | 出店はホストだけ（サーバーの部屋で core の操作を検証） |

## 2. オーナーの判断（2026-11-05）

| # | 論点 | 判断 |
| --- | --- | --- |
| 1 | 選んだ場所の効果 | **人口で少し変わる**（3種類の立地はそのままで、市区町村の人口で来客と家賃の倍率を少し変える。どこでも利益の見込みは同じくらいになるよう測って合わせる） |
| 2 | 出店候補地 | **全国の市区町村に3か所**（「〇〇市 駅前」「〇〇市 住宅街」「〇〇市 郊外」。架空の物件。地図上の印はその市区町村の中） |
| 3 | 共通市場 | **市場は1つの街**（作る人が市区町村を1つ選ぶ。全社がその街の駅前・住宅街・郊外に出店して客を取り合う） |
| 4 | 1店目 | **1店目も地図で選ぶ**（新しく始めるときに選ぶ。今のセーブの1店目は、場所を決めるまで標準の数字。経営メニューから1回だけ決められる） |

## 3. 地図データ

仕様テキストの配布元（`geo.maderaojen.me`）は、この開発環境のネットワークの設定で接続できず、CORS・提供の続き方・大きさを確かめられなかった。
そのため、**地図データをゲームに同梱する**（外部のサイトに頼らず、iPhone でも読み込みが小さい）。

| データ | 出典・ライセンス | 使い方 |
| --- | --- | --- |
| 都道府県・市区町村の境界 | npm `jpn-atlas@1.0.2`（BSD-3-Clause、元は国土地理院「地球地図日本」2016）。TopoJSON 1.3MB、市区町村 1,749（2014年の区域）・都道府県 47。SVG 用に投影済み | 生成スクリプトで「都道府県の形（全国）」と「都道府県ごとの市区町村の形」の SVG パスに変換して `apps/client/public/map/` に置く。都道府県を選んだときに、その都道府県の分だけ読む |
| 市区町村の名前・人口 | npm `jp-local-gov@2.6.0`（MIT。全国地方公共団体コード 2024年、令和2年国勢調査の人口） | コード（5桁）→ 名前・人口の表を core に置く（約60KB）。サーバー（共同経営・共通市場）も同じ表で出店を検証し、倍率を計算する |

- 2014年以降の合併などで名前の表にないコードは、近いコード（合併先）に寄せるか、出店できない区域として描く（生成スクリプトで数を確かめて記録する）
- 地図の画面と文書に出典を出す（「地図: 国土地理院『地球地図日本』（jpn-atlas）／人口: 総務省『令和2年国勢調査』（jp-local-gov）」）。ライセンスの文を `public/map/` に同梱する
- 仕様テキストの属性名（N03_001・N03_004）は使わない（同梱するデータに合わせる）

## 4. 経済（判断 1）

- 店ごとに場所（市区町村のコード）を持つ。来客と家賃に、立地の倍率（今の3種類）と **人口の倍率** を掛ける
- 人口の倍率は対数で小さめ: 人口10万人を標準（×1）に、1万人で下限・100万人で上限。**来客 ±10%・家賃 ±25%**（測った結果、いちばん良い値段での1日の営業利益は標準から −14%〜+8%。`docs/ECONOMY_BALANCE_AUDIT.md` 13章）
- 場所のない店（今のセーブの店）は倍率 ×1（今と同じ）
- 共通市場では街（判断 3）の人口の倍率を全社に同じだけ掛ける（市場の中の有利・不利はない）。サーバーの「上限を超えた日」の確かめ方（客の見込み）にもこの倍率を入れる

## 5. 画面

- **出店マップ**（新しい部品 `apps/client/src/ui/store-map.ts`）: 全国（地方の一覧）→ 地方 → 都道府県 → 市区町村 → 候補地3か所。SVG の viewBox で拡大縮小・ドラッグ・ピンチ・ホイール、選んだ区域の強調、候補地の印、戻る・パンくず、右（スマホでは下）に一覧と詳しい数字（来客・家賃・初期費用・人口）。
  iPhone の縦向きで画面を90度回して表示しているときも、指の動きの向きを合わせる
- **新しく始める**: 屋号のあとに1店目の場所を地図で選ぶ（「あとで決める」も選べる。決めるまで標準の数字）
- **経営メニュー**: 「会社」の出店は地図から（候補地を選ぶ → 店長を選ぶ → 確認）。1店目の場所が未設定なら「1店目の場所を決める」（1回だけ）。店の欄に場所を出す
- **共通市場**: 作る画面で街（市区町村）を地図か一覧で選ぶ。市場の画面の出店は、その街の地図（駅前・住宅街・郊外の印と空いている物件の数）
