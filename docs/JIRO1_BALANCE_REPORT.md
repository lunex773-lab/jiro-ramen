# じろ1 §8 経済バランスの検証（結果）

改修設計書 01（じろ1）§8「経済バランス検証（必須）」の結果。計画とオーナーの判断は `docs/JIRO1_PLAN.md`。

## やり方

- **細かいシミュレーション**（プレイヤーがいる店と同じ 0.1 秒刻み）で、10 パターンを 90 日まで回し、1・7・30・90 日の収支を項目に分けて記録した（`packages/core/test/econ/jiro1-balance.ts`）
- 店主は「全部の仕事をこなすボット」。**慣れていない人に近い遅さ（能力 0.4）**で回し、上手な人（能力 0.65）とも比べた
- ふつうの経営判断: 自動発注は「売れ行きに合わせる」、設備の定期メンテを予約、初めて黒字になってから従業員を雇う、雇った人が来ない日は短期バイト
- 種（乱数）を変えて複数回まわした平均
- 合格条件のうち、すばやく確かめられるもの（地域で戦略が変わる・営業時間の効果・客を増やしただけで利益が増えない・極端な値段と仕入れ・前のセーブ）は、毎回のテスト（`packages/core/test/econ/jiro1-criteria.test.ts`）でも確かめる

再実行:

```
cd packages/core
JIRO1_SIM=1 JIRO1_DAYS=90 JIRO1_SEEDS=777,778 JIRO1_OUT=/tmp/jiro1.json npx vitest run test/econ/jiro1-balance.test.ts
```

## 結果（2026-11-11。値段の効き方の調整・店長の役割・シフトの管理を入れたあと）

調整したこと（オーナーの判断 Q14）: 定価の1.3倍にすると得をしすぎていたので、満足度のうち「値段に見合うか」の重み 0.3 → 0.6、効き方の指数 2.5 → 3.5。
仕入れ値の1.2倍も試したが（上手な人 約7,400円/日・12席への拡張が33〜40日目と、前より難しくなった）、オーナーの判断で1.0倍のまま（多少簡単になるのは問題ない）。
