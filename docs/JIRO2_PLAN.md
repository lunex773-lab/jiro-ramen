## 2. まだないもの（このあと作る）

### 段階 A: 金融と市場（設計書04）
- **銀行の融資の上限 50万円**（オーナー: 額を選べる・返済能力で上限）: 5万円刻み、借入の残りの合計が50万円まで。返済能力 = 直近7日の営業利益の平均 × 30日分（最低20万円）を超えては借りられない。利率・返済日数は今と同じ
- **市場の参加 25社まで**: 26社目は断る。25社の0時の同期の負荷を測る
- **自分から市場を抜ける**（オーナー: 引退として抜ける）: 競争中でもできる。確認を出す。記録・順位は残り、店は市場から消える。借金は現金から返せるだけ返す
- **企業間の貸し借り**（オーナー: 自動で返す形）: 貸し手が借り手・金額・期限・利率（または無利子）を決めて申し込み、借り手が承認するとサーバーで資金を動かす。期限の日に借り手の現金から自動返済、足りない分は延滞（利息を上乗せして毎日自動で回収）。期限から14日返せなければ債務不履行（借り手は新しく借りられない・評判が下がる）。借り手はいつでも前倒しで全額返せる（利息は日割り）。借り手が抜けた・破産した・市場が終わったときは、現金から返せるだけ返し、残りは貸し手の損。二重実行を防ぎ、契約と返済の履歴を残す
- **市場の設定の変更の履歴**: 変更の確認（変える内容を出す）・履歴（時刻・作った人・変えた項目）。会社の数の上限は今いる会社の数より下げられない
- **在庫の二重処理のテスト**: 同じ日の送信を繰り返しても在庫・お金が二重にならない

### 段階 B: 武器とイベントの記録（設計書05）
- **武器を高額で買う**（オーナー: 案の2倍）: 包丁 6万・鉄パイプ 8万・金属バット 10万・日本刀 60万・拳銃 200万（弾1発 10万）・散弾銃 300万（弾1発 16万）・爆弾1個 100万円。一度買った武器は武器庫に残る。弾と爆弾は使うとなくなる
- **イベントの記録**: 爆発・事件（客を襲った）などを、ID・日時・会社・店・確率・状態・結果・復元の記録で残す（今のイベントの仕組みに足す）

### 段階 C: 従業員（設計書02）
- 勤務のカレンダー: 日・週・月の表示、従業員別・職種別、休憩、実際の勤務（遅刻・欠勤・残業）、勤務の重なり・休憩のおかしさの検出（シフトのデータは今の1つを使う）
- 仕込みの目安を「○人前」でも決められ、予想客数と比べる
- 自動仕入れ: 保存期間を過ぎる買いすぎを防ぐ・仕入れの履歴・食材ごとに自動の有効/無効
- 接客と仕込みが重なったとき、客の対応を先にする（テスト）

### 段階 D: 出店（設計書03）
- 候補地の数字（オーナー: 公的な統計を同梱）: 昼夜間人口比率（国勢調査2020）・小売業と飲食店の事業所数（経済センサス）を市区町村ごとに。交通量は場所（駅前・住宅街・郊外）と人口密度から。来客の見込みに少しだけ入れる
- 新規参入の保護（オーナー: 話題性＋段階的＋過密の注意）: 開店から14日は取り合いの重み ×1.3 → 1.0、既存の店との取り合いは7日かけて強める、競合の多い場所に「過密」の注意。利益は保証しない
- 近い店ほど強い取り合い（同じ市区町村の別の場所の店とも弱く取り合う）・同じ会社の店どうしも取り合う
- 出店のときの見込み（想定客数・予想売上・予想利益・初期投資・投資回収）と「見込みと実際は違う」の注意
