## 3. 設計上の論点（オーナーの判断が必要なもの）

1. **「信頼性」と「勤怠」**（4-1・4-3）: 今の能力「信頼性」は画面に数値で出ており、欠勤率を決めています。第2版の「勤怠」は数値を見せない隠しパラメータです。そのまま足すと、同じ意味の値が「見える信頼性」と「見えない勤怠」の2つになります
2. **シフトの時間の単位**（5-1）: このゲームの1日は「仕込み（時刻なし。プレイヤーが開店するまで）」と「営業 11:00〜15:00（実時間で約9分）」だけで、曜日もありません。勤務日・出勤時刻・退勤時刻・休憩をどの単位で決めるかを決める必要があります
3. **給与の形**（3-2・3-3）: 今は全員が日給。アルバイトを時給にするか、社員の給与・勤務条件をどうするか
4. **既存のセーブの従業員**: 雇用形態がない従業員を、読み込むときにどちらとして扱うか（経済を変えないなら「毎日・全時間のアルバイト」）
