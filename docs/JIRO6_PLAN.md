# 改修設計書 06: UI/UX 全面改善（じろ6）の計画

オーナーから受け取った改修設計書 06 に沿って、経営・市場などの画面を、見やすく・操作しやすく作り直す。
設計書の手順どおり、**今の画面を調べ → 画面ごとの改善計画と見た目の案を出し → 承認を得てから画面単位で作り替える**。
一度に全部を置き換えず、1画面ずつ作って確かめる。ゲームの計算（core）とサーバーには手を入れない（画面だけを変える）。

## 1. 今の画面の調査（2026-11-11）

iPhone 13 横（750×342）と PC（1280×800）で、3日営業して従業員が3人いる状態の画面を撮って調べた。

### 全体の問題

| # | 問題 | どこで | 例 |

| G2 | 一番大事な数字が先頭にそろっていない | 経営 | 先頭のカードは 現金・今日の営業利益・評判・来客 の4つ。売上・最終利益・負債・在庫・勤務の状況は下の方か、ほかのタブ |

### 画面ごと

- **経営**: 数字のカード4枚＋お金の流れ＋2週間の棒＋翌日の予測支出＋営業時間。売上・最終利益・負債・在庫・勤務が上にない
- **市場**: 1枚の長いページに、状況・順位・自社・出店・採用・貸し借り・設定がすべて縦に並ぶ。自分の順位・シェアが先頭にない
- **従業員**: 1人ずつ大きなカード（名前・担当の選択・見た目・ボタン5つ・能力の棒・疲れ・まとめ）。人数が増えると長くなり、「社員にする」が下に隠れやすい
- **在庫・発注**: 食材ごとの行に、在庫・パックの値段・翌朝便・当日便・自動 ON/OFF・目安の量の −/＋ が詰まっている。「在庫」と「仕込み予定」「入荷予定」の区別が文字だけ
- **融資・貸し借り**: 「借入の総額」と「返済の残り」が分かれていない
- **出店・設定**: 地図はよい。設定は項目が縦に並ぶだけ

## 2. デザインのきまり（全部の画面で共通）

- **色**: 地の色は落ち着いた黒〜こげ茶。黄色（店の色）は「選んでいるもの」と「いちばん押してほしいボタン」だけに使う。
  良い・悪い・注意（緑・赤・オレンジ）は数字の変化と状態だけに使う
- **文字**: 大きさを5段（10・12・14・20・28px 前後）に決める。数字は桁がそろう字形（等幅の数字）
- **数字のカード**: ラベル（小）・数字（大）・前日との差や補足（小）。**実績／今日（営業中）／予想** の札を付けて区別する
- **表**: 比べる数字は表にし、右そろえ。シェア・割合は横の棒を付ける
- **状態の札**: 勤務中・休み・遅刻・療養・欠勤などは色付きの小さな札
- **ボタン**: 押す場所は高さ 44px 以上（表の中の小さいボタンも、押せる範囲は 44px）。
  いちばん押してほしいもの1つだけ黄色。危ない操作（解雇・市場を消す・引退）は奥（「…」や設定）に置き、必ず確認を出す
- **操作の結果**: 押したらすぐ「〜しました」を出す。変える前と後を見せる確認。取り消せる操作は「元に戻す」。送信中は押せなくする（二重に送らない）。
  断られたときは「理由」と「どうすればよいか」を出す
- **説明**: 数字の意味は「？」で開く説明（売上と利益、借入の総額と返済の残り、市場の順位と全国の順位 など）

## 3. 画面の骨組み

- **経営メニュー**: 上の横のタブをやめ、**左に縦のナビ**（アイコン＋短い名前）。見出しは1行に細くして、中身に使える高さを増やす（iPhone 横で 240px → 約300px）
- **市場**: 1枚の長いページをやめ、**上の切り替え（順位・自社・出店と採用・貸し借り・設定）** に分ける。どの切り替えでも、先頭に自分の順位・シェア・売上・企業価値
- **PC**: 同じ骨組みで、横に広い分だけ数字のカードを1列に並べ、表やグラフを横に並べる

## 4. 見た目の案（画像）

`docs/jiro6-mock/` に置く（iPhone 横と PC）。

- 経営: 先頭に8つの数字（現金残高・売上・営業利益・最終利益・負債（返済の残り）・在庫・来客・今日の勤務）、昨日のお金の流れ（売上から費用を引いて営業利益まで）、14日の推移（売上の棒と営業利益の棒・目盛り）、気をつけること（そこから操作できる）、今日の勤務、在庫があと何日もつか
- 従業員: 1人1行の表（名前・雇用・担当・今日の状態・能力・給与・シフト・操作）。**「社員にする」は各行の右端に必ず見える**。行を選ぶと下にくわしい欄
- 市場: 先頭に自分の順位（この市場）・シェア・売上・企業価値・全国の順位（コミュニティ）・市場のイベント。順位表（シェアの棒・売上・企業価値・前日からの順位の変化）とシェアの内訳

## 6. オーナーの判断（2026-11-12）
