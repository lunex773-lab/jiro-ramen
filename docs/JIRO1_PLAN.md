## 4. 赤字の原因（分類）

1. **営業が4時間だけで、固定費（約12,700円/日）を回収しにくい**。損益分岐は約22〜25杯/日。ボットでも人の遅さ（能力0.2）だと1日目は赤字、慣れても利益は約2,400円/日。実際に人が操作すると、調理・提供・片付け・経営の判断を一人で行うため、さらに杯数が出にくい
2. **最初の客が少ない**: 評判の初期値 2.6 で来客は ×0.75（1日目 29〜37人）
3. **共通市場では客を取り合う**: 1地域に2社で ×0.71。AI 企業は計算だけで営業するので、人が操作する会社より杯数が出やすい
4. **不具合（直した）**: 自動営業の日に常連がいなくなり（常連の来客の増え方 最大 +60% が消えた）、翌朝の納品もなく在庫が減っていった
5. **廃棄が売上の約8%**: 仕込みの量と期限で捨てる分が多い（仕込みの目安を決められない）
6. **人件費が地域・能力に関係なく乱数**: 1人あたり約10杯しか増えないのに日給 5,000〜8,500円
7. **値段**: 定価の1.15倍前後が一番得で、安くすると成り立たない（満席が続くため）

## 5. 改修案

数値はすべて初期案。実装したら 6 章の測定で確かめて直す（一律の倍率で全体を変えることはしない）。

### 5.1 営業時間（じろ1 §2）

- 店ごとに **営業の枠（1日に最大3つ。例: 11:00〜15:00 と 17:30〜23:00）** と **定休日の曜日** を持つ。日をまたぐ枠（例: 18:00〜翌2:00）も可。今のセーブは 11:00〜15:00 のまま
- 時間の進み方は今のまま（ゲームの1時間 = ×1で実時間2.25分）。長く営業すると1日が長くなる（11〜23時なら ×1で27分、×5で約5分）
- 枠と枠の間は「中休み」: 仕込みと同じく時間が止まり、次の枠の「開店する」で再開（並んでいる客はそのまま）
- 定休日は営業せずに精算（家賃・維持費・社員の給料はかかる。工事の休業と同じ）
- 費用: 光熱費の基本を **1時間あたり** にする（今の2,500円/4時間 → 625円/時間）。家賃は1日あたりのまま（長く開けるほど家賃の割合は下がる）。仕込みは今も需要の見込みに合わせて量が変わる
- 営業時間を変えたら **次の営業日から**（営業中に変えても今日は変わらない）
- 変更するファイル: `types.ts`（StoreEntry.hours）・`sim/step.ts`・`sim/day.ts`・`sim/customers.ts`（時間帯）・`sim/staff.ts`（シフトを時刻で）・`sim/manager.ts`・`market.ts`・`verify.ts`（上限を営業時間で）・`save.ts`（移行）・`ui/manage.ts`（営業時間の画面）・`ui/hud.ts`（時計）

### 5.2 客数（じろ1 §3）

- 時間帯の山を **時刻で** 決める: 昼（12:00〜13:00）と夜（18:30〜20:00）の山、深夜は低め。都会ほど夜と深夜が高く、田舎は昼が中心
- 1日の来客 = 開けている時間の需要の合計。**今の 11〜15時の営業の来客は変えない**（難易度を保つ）。夜も開ければ、そのぶん客が増える（人件費・光熱費も増える）
- 立地と人口密度・物価と値段・評判・競合・席と処理能力・行列は今の式に地域の値（5.5）を入れる
- 評判の初期値・基本の来客の数は変えない（一律に増やさない）

### 5.3 行列（じろ1 §3）

- 店の入口（外）で **先に食券を買ってから** 列に並ぶ。券売機は入口の外に置く
- 外の列は **2列**（並べる人数を約2倍に）。並ぶかどうかは今どおり列の長さで決める（長すぎる列には並ばない＝機会損失）
- **外の列では我慢が減らない**（待たされていると感じない）。店の中で待つときだけ減る。中で待ちきれずに帰る客には食券を返金する
- 閉店時刻を過ぎても、**並んでいる客は解散せず** 最後まで提供する（新しい客は並べない）。閉店後の提供に使った時間も人件費・光熱費に入る

### 5.4 茹で時間（じろ1 §4）

- 理想 18秒（約8分）→ **15秒（約6分40秒）**、品質の幅（±3秒で最高・±12秒で0.25）はそのまま。ボットでは杯数の差が小さいので、人が操作するときの待ちを減らすのが主な効果。複数の種と人の遅さのボットで確かめてから決める

### 5.5 地域の経済・値段（じろ1 §5）

- 市区町村ごとに: 人口（ある）・**人口密度**（同梱の境界の形から面積を出す）・**物価指数**・**所得の目安**・**人件費の水準（都道府県の最低賃金）**・**値段の許容度**
- 物価指数と所得の目安は、公的な統計（消費者物価地域差指数・県民所得）を同梱したい（7 章の質問）。使えない場合は「都道府県の最低賃金＋人口密度」から作る目安で代える
- **仕入れ値** × 物価指数（約0.95〜1.05）、**家賃** × 人口密度と物価、**給料** は 5.7
- **値段と満足度**: 「値段に見合うか」の基準の値段 = 定価 × 地域の値段の許容度（都会・高所得ほど高い）。田舎・低所得ほど、基準を超えたときの満足度の下がり方を大きく、量（大・ダブル・ヤサイ増し）の満足を大きくする。品質・量・評判も今どおり効く
- **値段の上限を 5,000円**（画面・検証・共通市場の AI の上限）。高くしすぎた店は客が大きく減り、満足度・評判が下がる
- 変更するファイル: `data/municipalities.ts`（生成し直す）・`scripts/build-map-data.mjs`・`sim/location.ts`・`sim/customers.ts`・`sim/inventory.ts`（仕入れ値）・`sim/actions.ts`（上限）・`market.ts`（AI）・`ui/manage.ts`・`ui/store-map.ts`（地域の数字を出す）

### 5.6 出店できる場所

- **2〜5店目は1店目と同じ都道府県**、**6〜10店目は同じ地方**（北海道・東北・関東・中部・近畿・中国・四国・九州沖縄）、**11店目から全国**。店の数の上限はなくす（Q3）
- 共通市場も同じ決まり（市場の街は1店目の街。客の取り合いは同じ市区町村の店どうし）
- 地図の画面で、出せない地域は薄く表示し、理由（「6店目から」など）を出す

### 5.7 給料（じろ1 §6）

- 時給 = **その店の都道府県の最低賃金** ×（担当: 接客・清掃 1.00、調理 1.06、シフトリーダー 1.20）×（1 + 0.30 × 能力の平均 + 経験の分）。候補ごとに少しのばらつき（±5%）。**最低賃金を下回らない**
- 社員: 1日の給料 = 時給 × その日の勤務時間 × 1.15（今の昇格の割り増し）。休みの日の扱いは今どおり
- **深夜（22:00〜5:00）は25%増し、1日8時間を超えた分は25%増し**（労働基準法の考え方）。6時間を超える勤務は休憩45分（給与なし・その間は働かない）、8時間を超えると60分
- 地域の人材: 最低賃金が高い地域ほど候補の能力が少し高い、など（初期案。測って決める）
- 従業員の画面: 能力のバーを **採用したときの値（灰色）と伸びた分（色）** に分ける
- 今いる従業員の給料: 次の朝に新しい式で計算し直す（下がる人は下げない、の扱いを 7 章で確認）

### 5.8 担当・仕込み・店長の仕入れ・カレンダー（じろ1 §7・§10）

- **仕込み担当をなくす**: 仕込みは接客担当の仕事に入れる（接客の手が空いたときに仕込む）。今の仕込み担当は接客担当に変える
- **仕込みの目安**: 品ごと（ヤサイ・豚・アブラ・ニンニク・スープ）に「自動（売れ行きから）」か「◯杯分」を選べる
- **シフトリーダー**: 仕入れ・仕込み・調理・接客・清掃を全部する上位の役職。社員から昇格（目安あり）。給料は 5.7
- **店長の自動仕入れ**: 店長がいる店（プレイヤーがいる店も）は、店長が閉店後に、需要の見込み（曜日・営業時間）・在庫・仕込みの目安から翌朝便を発注する。資金が足りないときは必要な分（麺・豚骨）を先に、手元資金の一定割合までしか使わない。設定（店長に任せる／自分で）と、毎日の発注・欠品・廃棄の実績を画面に出す
- **勤務のカレンダー**: 全員の勤務（アルバイト・社員・シフトリーダー・店長）が入った月のカレンダー。日をタップすると、その日の全員のシフトを見て直せる（今の一人ずつのカレンダーは残す）

### 5.9 イベント・速さ・共通市場の設定・常連

- **バズの長さ**: 1時間〜3時間のあいだで30分刻み（1時間・1時間30分・2時間・2時間30分・3時間のどれか）を、バズが起きたときに決める。長いほど客が多く来る
- **爆発**: オンライン市場の端末で営業する日にも起きる。**2日目以降、まだ一度も起きていない会社（店）は1日 0.1%**、一度起きたあとは通常の 0.001%（ひとりの経営も同じ決まりにするかは 6 章の質問）
- **5倍速**: ×1 → ×2 → ×3 → ×5 → ×1
- **部屋の設定を後から変える**: 作った人だけ、市場の画面から、名前・説明・公開/非公開・AI で埋めるか・会社の数の上限（今いる数より下げない）を変えられる。期間・街・値段の決まりは途中では変えない（公平のため。7 章の質問）
- **常連の上限**: 60人 → 150人（常連による来客の増え方の上限 +60% はそのまま）

### 5.10 看板・店の周り

- 立て看板: 開店前・中休み・閉店後は「**準備中**」、営業中は「営業中」
- 店の周り: 出店先の地域で変える（都会: 高い建物・人通り・ネオン、駅前: 駅の高架・人通り、住宅街: 家と塀、郊外の幹線道路: 広い道・駐車場、田舎: 田畑と山）。人口密度と物件で決める
- 広告（周りの建物・店内の壁）: 今回は作らず、`docs/FUTURE_IDEAS.md` に記録する

### 5.11 画面のわかりやすさ

- 経営メニューと市場の画面を、**数字のカード（アイコン・大きな数字・前日との差の色）＋グラフ（損益の棒・7日の推移）＋短い文** にする。説明の長い文は「？」を押したときだけ出す
- 先に見た目の案（画像）を作って見てもらい、決まってから全部の画面に広げる

### 5.12 隠し扉と武器庫（Q1: 罰あり）

- 店の外の壁の一か所に、一見ではわからない隠し扉（壁の模様と同じ。近づいて調べると「押す」が出る）。中は小さな武器庫
- 武器を持つと、客に「攻撃」の操作が出る。表現はコミカルにし、血などは出さない
- 攻撃された客は逃げる。見ていた客も逃げ、評判が大きく下がる。警察が来て、その日の営業は終わる（精算へ）
- 共同経営ではホストだけ、オンライン市場の会社でも同じ罰（検証で評判・営業の終わりを確かめる）。チュートリアル中は扉が開かない
