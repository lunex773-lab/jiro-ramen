経済の数値は `ECONOMY_BALANCE_AUDIT.md`。

## 6. 一番大きな設計上の論点: 複数店舗の「見ていない店」の営業

今の店の営業は、客・従業員・調理・在庫を 0.1 秒刻みで動かす細かいシミュレーション（1日分で数千回の計算）で、iPhone では1店舗分が限界に近い。
2店舗目以降を「プレイヤーがいない間も同じ細かさで動かす」のは、端末でもサーバーでも重い。
選択肢（`EVOLUTION_IMPLEMENTATION_PLAN.md` で推奨案を出し、オーナーに確認する）:

1. プレイヤーがいる店だけ細かく動かし、ほかの店は「店長の営業」を1日単位の計算で出す（計算式は細かいシミュレーションの結果に合わせて調整し、テストで差を確かめる）
2. すべての店を細かく動かす（見ていない店は描画しない）
3. 見ていない店も細かく動かすが、時間を早送りでまとめて計算する（閉店後にまとめて）
