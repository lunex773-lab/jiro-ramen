# 経済バランス監査（統合進化設計書 v2.1 §4・Phase 0）

測定日: 2026-11-04。測定の仕組み: `packages/core/test/econ/`（`ECON_SIM=1` のときだけ動く）。
同じ乱数の種（777）・同じ初期条件（資金30万円・8席・初期の設備）で、経営のしかただけを変えて90営業日まで回した。
プレイヤーの代わりに「全部の仕事をこなすボット」（`addSoloBot`、能力0.65、給与0）を置き、壊れた設備はすぐ修理を頼む。
ゲームの規則・数値には手を入れていない（測定の前に見つけた AI の不具合だけ直した。下の 1 章）。

```
ECON_SIM=1 ECON_DAYS=90 ECON_OUT=out.json npx vitest run test/econ/economy-sim.test.ts   # packages/core で
```

## 0. 結論（要点）

1. **今の1日の利益は約 9,000円**（一人営業・8席、31〜90日目の平均 9,210円、利益率 20%）。90日で資金は 30万 → 110万円。既存の記述（6,000〜12,000円）と合う
2. **投資をすると利益が下がる**。調理担当を雇う（−4,500円/日）、黄色い大看板（−2,000円/日）、店舗拡張（拡張後 −9,800円/日）のどれも回収できない（回収日数 = 回収不能）。今の経済では「店を大きくする」という経営の判断が報われない
3. 原因は、**客は来ているのに店が出せる杯数が頭打ち**で、投資がその頭打ちを外せないこと（4 章）
   - 一人で出せるのは1日約46杯。来店は約60人で、毎日約17〜20人が待ちきれずに帰る
   - 人を雇っても、仕込み（ヤサイ・スープ）が追いつかず品切れが1日約30回出て、増えるのは約16杯。日給約7,500円に見合わない
   - 拡張しても来店の数は席の数で増えない（来客の式に店の大きさが入っていない）。家賃だけが増える
4. **価格を上げるほど得をする**（1.3倍で利益 +62%）。客が来すぎていて、値上げで減った分を待ち切れない客が埋めるため。低価格は成り立たない（0.8倍で利益 −75%）
5. 会計の誤り・抜け: 夜の自動発注の支払いが日報に入らない（日報の現金の増減が実際の約3倍に見える）、営業利益に利息を含めている、自動発注で冷蔵庫に入りきらないと必須の食材（もやし）が入らず店が回らなくなる
6. 拡張（12席）に必要な約76万円（工事60万＋移設約5万＋運転資金10万）がたまるのは約50営業日目＝実時間で8時間以上。しかもたまっても拡張すると損をする

## 1. 測定の前に直した不具合（aa27e44）

従業員 AI の「失敗した仕事を3秒避ける記録」をゲームの状態の外に、毎朝 0 に戻る時刻で持っていたため、前日の終わりに失敗した仕事を翌日のほとんどの時間選ばず、店が回らなくなることがあった。
最初の測定で、同じ条件のはずのケースの1日目が食い違い、いくつかのケースで提供が0杯になったことから発見。直したあとの測定が下の数値。

## 6. 調整の方針（案。数値は決める前にオーナーに確認する）

設計書 4.5 の順に進める。倍率を一律にかけない。調整前後を `test/econ` の同じケースで比べる。

1. **会計の修正**（数値は変えない）
   - 夜の自動発注の支払いを、その日の日報に入れる（期末の現金と翌日の期首を合わせる）
   - 営業利益（利息を含めない）・最終利益（利息を引く）・純売上を分けて日報と経営の画面に出す
   - 現金の増減の説明（純売上 − 現金で払った費用 − 仕入れ − 投資 ± 借入・返済）
   - 自動発注で冷蔵庫に入りきらないとき、必要な食材を先に・足りない分を比例して減らし、知らせる（もやしが入らず店が止まる問題）
2. **処理能力**（設計書 4.5 の 2・4）
   - 調理担当を雇ったときに仕込み（ヤサイ・スープ）が追いつかない原因を、品切れの内訳で特定して直す（AI の仕事の選び方か、設備の容量か）
   - 「人を雇う → 出せる杯数が増える → 利益が増える」が成り立つ範囲を作る（日給と増える杯数の釣り合い）
3. **店の大きさと来客**（設計書 4.5 の 5）
   - 来客の式に店の大きさ（席の数・店構え）を入れ、拡張すると来客が増えるようにする（席が足りないときは待ちきれずに帰る客が増える、という今の関係は残す）
   - 拡張の費用と回収日数を、決めた目標（下のオーナーの判断）に合わせる
4. **価格と需要**（設計書 4.6「低価格と高品質のどちらも成立」）
   - 高い価格は満足度（「値段に見合うか」）と口コミ・再来店に強く効くようにし、低価格は回転（たくさん出せる店）で利益が出るようにする
5. **費用の確認**: 修理費（純売上の約9%）・家賃の妥当性
6. それでも足りなければ、需要・価格・収益の係数を `BALANCE` で調整する

### オーナーの判断（2026-11-04）

- **上手に経営すれば、25営業日前後（実時間で約4時間）で12席に拡張でき、拡張で利益が増える**ようにする
- 1営業日は実時間9分のまま（操作の忙しさは変えない）

### 測定で新たに分かったこと

- **高価格が非常に有利**: すべてのメニューを1.3倍にすると1日の利益は約23,000円（定価は約9,000円）。客は59人 → 52人に減るだけで、出せる杯数（約46杯）は変わらない
- **拡張のあとに設備の故障が増える**: 杯数が増えると設備の使用回数が増え、2〜3日に1回、修理代 9,000〜15,000円の故障が起きる。定期メンテは初期状態で「予約なし」で、予約しないと状態が下がって故障しやすい
- 1つの乱数の種の比較はぶれが大きい（同じ設定でも1日の利益が数千円違う）ので、3つの種の平均で比べる
